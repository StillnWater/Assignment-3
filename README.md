# Assignment-3: Dashboard Application

A modern, interactive dashboard web application built with **React** and **Vite**. This project showcases a web development assignment with a focus on responsive design and interactive user interfaces.

## 🌐 Live Demo

Visit the deployed application: [https://assignment-3-lb42.vercel.app](https://assignment-3-lb42.vercel.app)

## 📋 Project Overview

This is a **web development assignment** that implements a dashboard application. The project demonstrates:

- Modern React component architecture
- Vite for fast build tooling and development
- Responsive web design with HTML, CSS, and JavaScript
- Best practices with ESLint configuration for code quality

## 🛠️ Tech Stack

| Technology | Purpose |
|-----------|---------|
| **React 19.2** | UI framework for building interactive components |
| **Vite 8** | Ultra-fast build tool and dev server |
| **JavaScript** | Primary language (65.5%) |
| **CSS** | Styling (32%) |
| **HTML** | Markup (2.5%) |
